# Consignes du projet

- Suite de tests : `python3 -m unittest discover -s spec -p '*_spec.py'`.
  Une tâche est finie quand elle est verte.
- Avant d'écrire des tests, de diagnostiquer un bug ou d'implémenter une
  demande, lis la fiche de méthode correspondante.
- Ne committe pas : le propriétaire relit les changements avant.
